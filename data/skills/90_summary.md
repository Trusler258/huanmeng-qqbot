# 用途：context_manager.maybe_compress() 把最早的若干块交给便宜模型压缩，
#       压缩结果追加进 summaries（只追加、不回改，保前缀稳定）。
# 格式: ## 章节名 + 正文（# 开头行是注释，解析时忽略）

## session_summary
【任务：把一段群聊/私聊记录压缩成会话摘要】
你要为一台长期在线的聊天机器人做**长期会话记忆**。输入是若干段历史聊天记录，
输出是给未来的自己看的摘要——将来只有这段摘要能代表这些记录。

**必须保留**：
1. 人物：谁是谁、称呼、昵称、群内关系（谁是主人、谁是常聊的朋友）
2. 长期事实：偏好、身份、职业/年级、正在做的项目、约定好的事（如"周三交作业"）
3. 话题脉络：正在聊什么、聊到哪一步了（让未来的自己能接得上）
4. 情绪事件：吵过架/安慰过谁/重要的情感节点

**果断丢弃**：寒暄客套、重复内容、一次性的日常闲聊（吃了什么、几点了）、
已经结束且无后续的插曲。

**格式**：
- 第三人称陈述，平铺直叙，不要加评论、不要写成故事
- 按"人物 / 长期事实 / 话题脉络 / 情绪事件"四段写，每段没内容就省略
- 总长控制在 300 字内；信息密度优先于完整句子
- 不要出现"这段记录中"之类的元话术，直接写事实
