## 缩写/字母梗

- YYDS：永远的神。顶级夸奖。
- NSDD：你说得对（拼音首字母）。
- W：win 的缩写，表示"赢了/太棒了/认可"。例：这波操作，W。
- L：lose，表示"输了/拉胯/失败"。
- M3：You know what I'm saying 的谐音，= "你懂我意思吧"。
- Siu4：粤语"笑死"谐音，表示很好笑。
- MNYY：Must Need 要有，= "生活必需品/必须拥有"。
- SLDPK：笑到扑街（粤语，笑到摔地上），表示笑死。
- PUA：原指搭讪学，网络中指精神打压/操控（贬义）。例：别 PUA 我。
- 已读不回：对方看了消息却不回复。
- 破防：心理防线被突破，情绪瞬间崩溃或破大防。
- 硬控：原指游戏强制控制技能，现形容强烈吸引力让人移不开眼。例：被这段视频硬控 30 秒。
- 触 / 触烂：英文 true 谐音，表"极对/超级认同/极致"。
- 包得 / 包的：保证、肯定、没问题、稳了。
- 要确欸："你要确定欸"的简写，表对对方行为表示质疑/傻眼。
- 各各：聚餐各付各的（AA 制）。
- 估咩：Google Maps 缩写。

## 语气/状态词

- 卡皮巴拉：水豚的昵称，形容人情绪稳定、呆萌治愈、不内耗。
- 晕碳：吃大量碳水后血糖波动导致的昏昏欲睡。
- 很解：很扫兴、很下头，让人瞬间冷静。
- 很躁：很烦躁、不耐烦。
- 很玄：敷衍回应，暗指背后有特殊原因说不清。
- 蒸笼 city：形容盛夏闷热得像蒸笼的城市。
- 活人感：指人真实鲜活、有情绪，不伪装、不 AI 式客套。
- 脑腐 / brainrot：沉迷低质网络内容导致的精神状态下降；也形容对某事物的痴迷（如"XX 脑腐"）。
- 蛋雕：谐音"丢掉"（台语），表把东西舍去/放弃某个想法。
- 泉：台语"溅"谐音，形容吹牛、夸大其词。例：别泉了。
- 贴脸开大：原为游戏术语（近距离放大招），现指直接针对对方痛点发起攻击。
- 破大防：比"破防"程度更重，彻底崩溃。
- choke：关键时刻掉链子、失误（电竞术语泛化）。

## 游戏圈泛化（QQ 群高频率）

- 菜/菜鸡：技术差（自嘲或调侃）。
- 送人头 / 白给：主动送死、白送（游戏泛化）。
- 老六：阴险猥琐、喜欢蹲人蹲点的人（原 CS:GO 打法）。
- 开黑：组队一起玩游戏。
- 带飞 / 躺赢：大神带节奏赢 / 自己躺着赢。
- 上分 / 掉分：排位分数上升 / 下降。
- 手残：操作跟不上反应，打不好操作类游戏。
- 欧皇 / 非酋：运气极好 / 极差（抽卡、掉落）。
- 空枪 / 空大：放大招却打空（泛化：把事情搞砸）。
- 退役选手：调侃自己或他人操作退步。
- 双排 / 车队：双人组队 / 多人固定车队。
- 击杀王 / 金牌打手等榜单称呼：指游戏内数据称号。

## MC 圈黑话（幻梦服务的主要人群）

- 破基岩 / 基岩层：Minecraft 世界最底层无法破坏的方块；"破基岩"是技术操作。
- 粘液块电梯 / 鞘翅 / 下界合金：Minecraft 常见道具/机制。
- AFK：离开键盘（挂机）。
- TNT 炮 / 红石科技：自动化装置。
- 生存/创造/极限：游戏模式简称。
- 端游 / Java 版 / 基岩版：版本区分。
- 炸服：服务器崩溃。
- 卡服：服务器卡顿。
- 氪金：花钱买游戏内物品。
- 肝：花大量时间刷资源（肝帝=刷子之王）。

## 社交/吹水

- 世一：世界第一的简称。
- 大癲：十分夸张、离奇。
- 6 翻了：形容 Very cool。
- 稳如老狗：非常稳定可靠（戏谑）。
- 什么鬼 / 什么玩意：表惊讶（疑惑）。
- 离谱：超出常理。
- 无敌：太强了。
- 绷不住：忍不住笑/忍不住了。
- 蚌埠住了：谐音"绷不住了"，忍不住笑。
- 双厨狂喜：两个都喜欢的东西同时出现，狂喜。
- 电子包浆：反复流传的网络梗/图，像文物包浆一样被"盘"久了。
